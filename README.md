# Xufeng He

Personal academic homepage: https://xufenghe.github.io/

A static site hosted on GitHub Pages. Edit `index.html` for content and `styles.css` for styling. Changes pushed to `main` are published automatically.

Before pushing, run `python3 scripts/check_site.py` to validate local asset references and basic accessibility metadata used by the page.

The Georgia Tech seal is used to identify academic affiliation and comes from https://brand.gatech.edu/our-look/logos.
